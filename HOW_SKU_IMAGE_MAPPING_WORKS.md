## 2️⃣ **Page Load** (Frontend Code)

**File:** `src/app/catalog/aandrijftechniek-grouped/page.tsx`

### Step A: Load the Mapping
```typescript
const [imageMapping, setImageMapping] = useState<Record<string, string>>({});

useEffect(() => {
  fetch('/data/aandrijftechniek_image_mapping.json')
    .then(res => res.json())
    .then(data => {
      setImageMapping(data);  // Now we have the SKU → Image dictionary
    });
}, []);
```

**Result:** Mapping file is loaded into memory as a JavaScript object:
```javascript
{
  "RLNUC205": "/images/.../p020_RLNUC205.jpeg",
  "RLNUC206": "/images/.../p020_RLNUC205.jpeg",
  // ... all 54 SKUs
}
```

---

### Step B: Load Product Data
```typescript
useEffect(() => {
  fetch('/data/aandrijftechniek_grouped.json')
    .then(res => res.json())
    .then(data => {
      // Apply mapping to each variant
      const dataWithImages = data.map((group: any) => ({
        ...group,
        variants: group.variants.map((variant: any) => {
          // HERE'S THE MAGIC: Direct SKU lookup
          const mappedImage = imageMapping[variant.sku];
          
          if (mappedImage) {
            return {
              ...variant,
              image: mappedImage,
              media: [{ url: mappedImage, role: 'main', type: 'image' }]
            };
          }
          return variant;
        })
      }));
      
      setProductGroups(dataWithImages);
    });
}, [imageMapping]);
```

## 🔐 Why This is 100% Reliable

### ✅ Direct Dictionary Lookup
- **No guessing**: Exact SKU match
- **No string matching**: Direct key-value lookup
- **No patterns**: Hardcoded mapping for each SKU

### ✅ Explicit Mapping
Every single SKU has an explicit entry:
```json
{
  "RLNUC205": "image1.jpeg",          // Explicit
  "RLNUC205G2L3": "image1.jpeg",      // Explicit
  "RLNUC206": "image1.jpeg",          // Explicit
  "RLNUC206G2L3": "image1.jpeg",      // Explicit
  // No guessing, no inference
}
```

### ✅ Validated at Build Time
The mapping file is generated by Python script that:
- Reads actual product groups
- Matches to actual image files
- Validates files exist
- Creates exact mappings

### ✅ Fail-Safe Behavior
```typescript
const mappedImage = imageMapping[variant.sku];

if (mappedImage) {
  // Use mapped image
} else {
  // Product appears without image (safe fallback)
}
```
No crashes, no broken images - just missing image if SKU not mapped.

## 🔄 How Mapping is Generated

### Python Script Creates Mapping
```python
# For each product group
for group in product_groups:
    image_path = find_image_for_group(group)
    
    # Map ALL SKUs in group to the same image
    for variant in group['variants']:
        sku = variant['sku']
        sku_to_image[sku] = image_path  # Direct mapping
```

### Saved as JSON
```json
{
  "SKU1": "image_path",
  "SKU2": "image_path",
  "SKU3": "image_path"
}
```

### Frontend Loads and Uses It
```typescript
imageMapping["SKU1"]  // Returns "image_path" instantly
```
